# ClaudeUnitySkills

A Claude Code plugin marketplace for automating the Unity Editor from chat.

## Install

```
/plugin marketplace add vantv/ClaudeUnitySkills
/plugin install unity-skills@claude-unity-skills
```

(Replace `vantv/ClaudeUnitySkills` with this repo's actual remote path if different, or use a local path/URL — see [Claude Code plugin marketplace docs](https://code.claude.com/docs/en/plugin-marketplaces).)

## What's inside

- [`plugins/unity-skills/`](plugins/unity-skills/) — the plugin itself. See its [README](plugins/unity-skills/README.md) for the full list of skills and what each one covers.
- [`.claude-plugin/marketplace.json`](.claude-plugin/marketplace.json) — the marketplace manifest that makes the plugin installable.
